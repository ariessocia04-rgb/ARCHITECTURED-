# ROS FOLDERIZATION STANDARD

All future structured results must be delivered as actual folders under this ROS hierarchy.

```text
Numbered Domain/
├── INDEX.md
└── Concern/
    └── README.md or approved canonical artifact
```

Rules: use clear numbering; keep one concern per folder; place a real file in every folder; use indexes for navigation; do not duplicate existing canonical architecture; save detailed work inside the correct concern folder.
